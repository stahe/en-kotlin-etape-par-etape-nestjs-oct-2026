    Step-by-Step Introduction to Mobile Programming with [Kotlin]

    created by Anthropic’s AI Claude at the request of Serge Tahé - October 2026

    |French version|

    This course teaches you, step by step, how to write a native Android mobile app using the Kotlin language and Jetpack Compose, Android’s declarative UI library: an app whose screens are rendered on the phone based on JSON data from a server.

    After setting up the development environment (Android Studio, emulator, Gradle), the course draws on 25 short examples, each focused on a single concept: activities and @Composable functions, state and recomposition, input fields, validation; component composition, their lifecycle, and their effects; CompositionLocal; animations; navigation (Navigation Compose) and its guards; coroutines, Flows, and shared state (ViewModel, DataStore); internationalization; and finally, communication with the server (OkHttp, cookies, kotlinx.serialization).

    The server is treated as a black box: it is the JSON server for the RdvMedecins app, written with NestJS. We’ll set it up, study its API, and query it using 48 curl examples—without having to read its code.

    Next comes a comprehensive case study: the RdvMedecins Android client, an appointment-scheduling app for a medical practice, with all files fully commented, followed by its deployment.

    This course follows the progression of the “Step-by-Step Introduction to the Flutter Mobile Framework” course, using the same examples, server, and case study. Prerequisite: a basic understanding of the Kotlin language, as covered in the Kotlin course.
